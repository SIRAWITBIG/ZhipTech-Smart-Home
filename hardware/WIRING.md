# Wiring review — ยังไม่ยืนยันวงจรจริง

ใช้เฉพาะโหลด DC แรงดันต่ำ ห้ามนำไฟบ้าน 220 V เข้ามาในชุดสาธิตนี้

ก่อนเปิด `HUB_HARDWARE_ENABLED` ให้ตรวจตามลำดับ:

1. ถอดไฟเลี้ยงทั้งหมดและยืนยันบอร์ด ESP32 รุ่นดั้งเดิม รวมขาที่เข้าถึงได้และ Flash จริง
2. อ่าน datasheet/ฉลากของ relay, PIR, IR, photo sensor, OLED, RGB และ buzzer ทุกตัว ห้ามสมมติว่า 5 V output ต่อเข้า GPIO ได้โดยตรง
3. แยกวงจรไฟเลี้ยงโมดูลกับระดับสัญญาณ GPIO; GPIO ESP32 ต้องไม่รับเกินพิกัดที่ datasheet อนุญาต ใช้ level shifting ตามความจำเป็น
4. ยืนยันกราวด์ร่วมที่เหมาะสมและพิกัดแหล่งจ่าย เพิ่มวงจรขับเมื่อโหลดกินกระแสมากกว่าขา GPIO รองรับ
5. ต่อปุ่ม GPIO39 พร้อม external pull-up ไป 3.3 V ใช้ ADC1 GPIO34/35 โดยไม่ป้อนแรงดันเกิน 3.3 V
6. ใส่ตัวต้านทานจำกัดกระแส LED ทุกดวงและ RGB แยกแต่ละสี ยืนยัน common anode/cathode
7. ต่อโหลด DC จำลองผ่าน COM/NO ของรีเลย์สองช่อง ตามโมดูลจริง ตรวจ active-high/low และสถานะตอน reset ขณะยังไม่มีโหลดก่อน
8. ตรวจ OLED controller/address ด้วย I2C scanner ที่เหมาะสมก่อนเปิดไดรเวอร์ SSD1306
9. ทดสอบทีละส่วน: safe boot → DHT → photo/pot → PIR/IR/button → LEDs/relay → buzzers → OLED → API
10. ตรวจว่าการรีเซ็ต/ไฟดับ/ต่อ Wi-Fi ไม่สำเร็จไม่ทำให้รีเลย์หรือ buzzer ติดโดยไม่ตั้งใจ ใช้ pull resistors ทางกายภาพตามความจำเป็น เพราะซอฟต์แวร์ควบคุมสถานะก่อนเริ่ม CPU ไม่ได้

เฟิร์มแวร์ตั้ง latch ปิดก่อนกำหนดขา output แต่ยังไม่พิสูจน์พฤติกรรม electrical boot ของวงจรจริง PIR มี warm-up 60 วินาที และ DHT อ่านทุก 2.5 วินาที สถานะ photo เป็นเปอร์เซ็นต์สัมพัทธ์ ไม่ใช่ Lux

การ compile ผ่านไม่ยืนยัน wiring, polarity, กระแสไฟ, ความแม่นยำเซนเซอร์ หรือความปลอดภัยของฮาร์ดแวร์ ห้าม flash/upload จนกว่าผู้ใช้อนุญาตและตรวจวงจรเรียบร้อย
